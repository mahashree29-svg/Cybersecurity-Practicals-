# 🕵️ Footprinting and Reconnaissance — Practical Lab

A complete hands-on lab series demonstrating **Footprinting and Reconnaissance** techniques used in the **Information Gathering** phase of ethical hacking. These practicals teach how to collect publicly available information (OSINT) about a target domain, organization, or individual using free, open-source tools available in **Parrot Security OS** / **Kali Linux**.

> ⚠️ **Disclaimer:** All practicals are intended for **educational and authorized penetration testing purposes only**. Do not perform reconnaissance against systems, websites, or individuals you do not have explicit permission to test.

---

## 🎯 Learning Outcomes

After completing all the practicals, you will be able to:

- Perform passive reconnaissance using public databases.
- Use both **GUI tools** and **command-line frameworks** for OSINT.
- Understand the **footprinting phase** of ethical hacking.
- Document findings effectively for penetration testing reports.

---

## 🛠️ Prerequisites

- **OS:** Parrot Security OS / Kali Linux / Ubuntu
- **Tools:** `whois`, `theHarvester`, `recon-ng`, `sublist3r`, `python3`, `git`
- **Browser:** Firefox / Chromium for web-based tools
- **Basic Knowledge:** Linux terminal, networking fundamentals
